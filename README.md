# 🎬 CineCrit – Movie Review Website

**CineCrit** is a modern and responsive movie review website built using **HTML**, **CSS**, and **JavaScript**. It allows users to search for movies, view ratings, and watch trailers — all in a sleek and user-friendly interface.

---

## 🚀 Features

- 🔍 **Search any movie** instantly
- ⭐ **Display movie ratings** from trusted sources
- 🎞️ **Watch trailers** directly on the website
- 📱 **Fully responsive** design for mobile, tablet, and desktop
- 🎨 **Attractive UI** using clean HTML & CSS
- ⚡ **JavaScript-powered interactivity**

---

## 🛠️ Technologies Used

- **HTML5** – Structure  
- **CSS3** – Styling & layout  
- **JavaScript** – Functionality & API integration
